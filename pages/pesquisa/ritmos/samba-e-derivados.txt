
Marcha (MM = 112 a 132)
Convenção 1: Levada Tradicional
Compasso 2/4 — acompanhamento de violão — notação em LilyPond:
Observação: acordes simplificados (Dó no 1º compasso, Sol7 no 2º). O ritmo e o baixo foram lidos da figura do livro; conferir no editor antes de usar.

\version "2.24.0"
\header { title = "Marcha (MM = 112 a 132)" }
\score {
  \new Staff {
    \clef "treble_8"
    \time 2/4
    \repeat volta 2 {
      <<
        \new Voice { \voiceOne
          r8 <e g c'>8 r8 <e g c'>8 | r8 <d f b>8 r8 <d f b>8 |
        }
        \new Voice { \voiceTwo
          c4 g, | g,4 d |
        }
      >>
    }
    <c e g c' e'>2 \bar "|."
  }
}
