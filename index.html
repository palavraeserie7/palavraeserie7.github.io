Use as informações abaixo para enriquecer seus sermões e estudos bíblicos. Conteúdo liberado para pesquisa.

1. Raízes Linguísticas (M03)

A expressão "O Senhor é meu Pastor" utiliza o termo hebraico Jehovah-Raah. Diferente de um guia turístico, o Raah é aquele que se mistura ao rebanho para sentir suas necessidades.

2. O Contexto do Deserto (M02)

Os "pastos verdejantes" surgiam no meio das pedras. A lição é: Deus provê o suficiente para o dia, mantendo-nos dependentes d'Ele.
